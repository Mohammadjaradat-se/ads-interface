# Ads Platform UI

A simple advertisement platform user interface built using HTML and CSS.

## Features
- Clean and modern design
- Product advertisement cards
- Responsive layout
- Simple and user-friendly interface

## Technologies Used
- HTML5
- CSS3

## Live Demo
https://mohammadjaradat-se.github.io/ads-interface/

## Purpose
This project was created to practice front-end development fundamentals, including layouts, card components, styling, and responsive design using pure HTML and CSS.
